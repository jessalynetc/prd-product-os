# Build-Ready PRD Template

0. Document Control
1. Executive Summary
2. Problem & Evidence
3. Product Thesis & Principles
4. Goals & Success
5. Scope — P0, P1, P2, non-goals, never-cut, cut order
6. User Experience Architecture
7. Functional Requirements
8. Non-Functional Requirements
9. Content / Domain / Data Model
10. Technical Architecture
11. Build Plan
12. Validation Plan and Definition of Done
13. Risks / Assumptions / Dependencies / Open Questions
14. Decision Log
15. Future Work

Adapt depth to the project. Do not fill sections with boilerplate.

Decision log columns: Decision, Reason, Alternative Considered, Trade-off, Status.
